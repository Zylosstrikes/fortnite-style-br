# Storm Royale 3D
Original low-poly 3D battle royale (Three.js r152 bundled locally, no CDN, no build step, all art procedural).

Run: `cd fortnite-game && python3 -m http.server 8000` then open http://localhost:8000
(opening index.html directly also works in most browsers).

Controls: press H in game for the full list.
